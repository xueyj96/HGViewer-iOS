# HGViewer 控件与尺寸标准

2026-11-11 · 1.1.106 · 本轮用户已授权选择、修复并统一；下表为已落实的项目标准。交付与真机体验分别验收，不用源码通过代替设备验收。

## 范围与证据

标准覆盖当前全部8个页面模块及频道、榜单、图文详情等子入口、共享导航和24个TSX组件模块。共42类控件/布局角色，分类数不等于屏幕可见实例总数。[逐类清单](ui-dimensions-inventory.json)记录共享实现、调用页面、源码、可见框、操作区、字形、字阶、留白、圆角及例外。

本轮先由三路独立只读审查盘点导航、控件、内容，再实施并独立复审。生产iOS前端使用Chrome及模拟原生接口，覆盖390竖屏、844横屏、320窄屏、149–260键盘可视高度；原生iOS打包通过。真实WebKit长按、选择器新样式支持、系统大字号和左右刘海延迟仍需要设备体验确认。

仓库内的CSS px为Web布局单位。44是本App的常规操作目标，并非声称所有系统控件的最低尺寸是44。系统和其他App的数值不直接迁移到本App。

## 弹窗与内容页

确认框与诊断框首选宽320、高180，**窄屏保留两侧至少16：320视口实际宽288**。内边16、标题居中、正文区60高，左右动作各88×44点击/88×36可见。确认标题/正文/按钮文案仍限16/60/4字；诊断正文完整滚动，不按60字截断。

关于页改为完整内容页，复用固定顶底栏，顶部提供返回与复制版本。账号/线路/评论/详情同样使用整页共享导航；清晰度等短选项保留半屏。非iOS的内容弹窗保留平台原布局。

## 保留与合并的依据

- 合并：搜索标签26→28，开关51×31→40×24，头像30/34→32，输入间距10→8；小点击区补44，HTML/纯文共享阅读角色。
- 保留：输入/选集整面44、辅助动作28、开关胶囊形、下载6/排名3、媒体原比例、沉浸/内嵌播放两档。它们分别服务不同任务，不是任意数字例外。
- 选择器使用浏览器内置select机制与CSS渐进样式；不维护一套JavaScript选值器。旧浏览器保留原生功能，外观兼容性单独验收。
- 桌面窗口按钮、鼠标导航和系统红绿灯使用平台尺度；本轮没有把触控44要求强套到桌面窗口装饰。

## 验证与维护

1.1.101 历史基线回归记录在 `build/releases/1.1.101/verification/`：尺寸/弹窗、整页/表单/键盘、历史生命周期、菜单指针/键盘/权限；独立复审闭环了全屏事件区压小、加载圆环拉长、外点穿透三项问题。测试原生接口为模拟，真实iPhone的长按、Popover焦点、可定制select支持、系统Dynamic Type、两方向刘海和缩放体验仍按设备实测记录。

当前 1.1.106 的消闪逐帧对照及六组分栏双向回归见 `build/releases/1.1.106/verification/`；完整菜单、尺寸、表单及历史回归分别保留在 `build/verification/cover-menu-lift/` 和 `build/verification/tab-swipe/`。这些是本地验证记录路径，不随公开源码上传。

固定字号网页目前不声明自动支持所有系统Dynamic Type档位，也没有新增文字自动缩小策略。长文允许换行/滚动、操作区不缩小；系统字号与缩放测试是后续设备验收项，不能用源码中没有minimumScaleFactor就声称已验收。

规范值集中在 `src/ios.css`，组件选角色和变体。新调用不再单独发明输入间距、行高或字号；同一位置的加载/选中/禁用/失败保持外框。清单保留旧盘点为baseline字段，当前源码哈希与本轮结果重新核对，避免只刷新哈希却沿用旧结论。

跨App仅共享分类与证据字段，不要求ExHViewer、Civit Viewer与HGViewer使用同一组数值。此文件是HGViewer自身标准。

1.1.103 专项验证见 `build/verification/cover-menu-lift/`：真实触摸事件松手保留、带图封面克隆与隔离、淡出归位、Tab焦点、关闭中旋转/重开、重复动作去重、减少动效，以及原生select展开/选值。浏览器模拟原生接口，不能代替目标iPhone手势体验验收。

1.1.104：数量选项与封面操作项共享固定44高、R4、横12、14/20/400。外框R8/内4；普通项垂直居中；辅助文字11/16，带说明项按20+16+上下4排在同一44高内，单行溢出省略，完整说明留在title和aria-description。

1.1.105：顶栏分栏统一由 IOSTabSwipe 管理。左右边缘向内切相邻栏，正文与选中指示块跟手；顶底栏不跟随位移。指示块继续使用原28可见面与44点击区，完成200ms/回弹170ms。六组覆盖分类、资料库、榜单、频道排序、账号、详情与选集。原有表单、分页和缓存副作用只在提交后发生；手势与长按互斥。顶栏布局或动作变化由固定host内的内容槽位过渡；文字不缩放。新增验证位于 build/verification/tab-swipe/，包含竖横屏各8组、登录键盘149–260高度与80条历史回归。

1.1.106：分栏交接保持结束帧，索引提交后才释放动画。逐帧对照在延迟提交80ms时复现旧实现0→1→0→1，新实现0→1；反向、回弹、减少动效、禁用/旋转/卸载清理见build/verification/tab-flash/。
