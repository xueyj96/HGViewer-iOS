# HGViewer 第二轮整体优化

基线为已发布且获用户真机确认的1.2.5。本轮目标是降低横切责任的维护成本、修复实际发现的状态时序问题，继续与ExHViewer、CivitViewer讨论共同契约。只修改HG源码；不变更版本、存储键、原生下载格式或站点协议，不包含安装和发布。

## 范围与实际决策

| 责任范围 | 本轮结论与改变 | 保持的边界 |
| --- | --- | --- |
| AppShell、workspace和页面栈 | 核对路由与线路数据范围；远端列表／图文栈内容按lineRevision重载，route identity与固定栏保持 | Settings及本地缓存页面不随线路重建；播放Feature单独保留 |
| 播放、详情与预取 | Feed详情／图文和Source地址三个记录共用useRevisionRecord；旧revision不可覆盖新值，预热按线路隔离 | 保留选中作品、集数、暂停意图、Progress及原生attempt分责；不把重试计为第二次首次历史 |
| 手势与方向 | 非活动播放页移除resize/layout/touchmove订阅；保留需要preventDefault的非passive监听 | 方向队列、首末集回弹、长按倍速与原生安全区策略保持 |
| 本地状态与互动 | 喜欢／关注改显式目标动作；喜欢、收藏、关注共用纯membership策略 | 提示和API使用同一目标，不在updater里执行副作用或取得返回值；站点收藏同步仍属原服务 |
| 持久化 | 新persistedPreferences集中v1读取校验；有效字段保留，坏字段分别回退，兼容旧历史 | 保留键名、字段、收藏顺序、历史规则与音量；没有清理或迁移手机数据 |
| Toast | 独立展示快照与稳定actions，业务Store不再订阅提示列表；卸载清理timer | 历史撤销scope与普通收藏撤销分别保留；不声称已测量整机帧率收益 |
| 缓存页面与下载状态 | offlineStatusStore持有唯一读取与轮询；操作后读取串行，旧结果不发布；隐藏页面不订阅快照 | 原生任务及续传分片不属于页面；失败保留旧可信state并显示readError |
| 请求与列表 | 桌面分类两频道与帖子有界并发，保留各支失败隔离 | 不引入SWR、Next或新的请求框架，不把独立请求并发套到有依赖的原生命令序列 |
| 控件、尺寸与动效 | 生产CSS只读token报告含角色、来源SHA、原始表达式和未解析范围；共同结果语义写入v2补充 | 不重新手写一份尺寸来源、不统一不同平台单位、不改已验收界面外观；finishMotion只做视觉cleanup |
| Rust／Objective-C服务 | 核对下载状态端口、后台／续传owner、源与会话边界，保留现有队列／传输分层 | 本轮原生源码未改，不声称对全部原生实现做了新的动态回归 |

这是一轮跨责任的架构检查和具体修复，不是逐行审计全部历史源码。页面模板入口、源码未变更范围、浏览器测试和真机验收分别记录。没有发现相同变化原因或实测收益的部分保留原实现，避免为形式统一增加文件和间接层。

## 独立审阅与纠正

Civit会话只读审阅实际HG源码，支持保留H0–H4分责、分离业务／导航／视觉结果和token单一生产来源。复审提出两处P2，均在本轮处理：

1. 隐藏缓存页面仍订阅每次快照。现使用稳定空订阅，激活后直接读取当前snapshot；回归验证活动A更新、隐藏B不更新、B激活立即取新值。
2. 最初按页面kind重建Feed会连带重建offlineItems本地播放，丢失选集及进度。该候选已撤销。现在保留Feed实例，仅使远端记录失效；三处真实记录消费者共用小型revision策略，没有第二套播放session。

修改后的受影响生产源码已获该会话有限通过；审阅不替代运行结果。ExH会话已收到讨论请求，仍在处理本会话自己的界面任务；其本轮意见未收到前，不能把v2补充写成三方新一轮全部批准。已有v1三方约定继续有效。

测试自身也作了两项纠正：顶栏测试需原有trusted pointer bridge，通用runner缺桥时的3项失败不能算产品回归；缓存往返Settings本来就关闭并正常重开原生播放器，验收应为不额外重建Feature、仍选中第2集、恢复23秒，而非要求native open总数不变。测试只操作真实可交互按钮，排除inert的旧栏视觉克隆。

## 验证与证据

证据目录为`build/verification/architecture-20261112`，由来源指纹绑定结果。最终构建和回归状态以该目录`closure.json`为准；若源文件再次变化，相应检查应重跑。

- 状态／策略测试涵盖v1数据兼容、坏字段隔离、纯目标动作、revision旧writer拒绝、缓存读取互斥和失效、Toast订阅与计时器清理。
- 实际App模拟IPC涵盖五类远端路由换线、Settings／导航实例保持、本地缓存管理独立、在线及缓存选集和23秒续播、隐藏缓存订阅。
- 原有来源、进度、手势、顶栏命中、HTML与安全设置、观看历史继续回归；浅深两色页面入口与桌面分支检查单列。
- 浏览器／模拟IPC不证明WebKit触摸手感、AVPlayer实际解码、iOS后台调度或真机旋转。这轮没有安装包与真机交付，手机仍为用户已验收的1.2.5。

## 保留的工程选择

Store仍是多数业务状态的公共facade。已证明Toast广播可以独立消除，故先处理；其余Context划分需要对实际热路径计数或性能采样，不能由“单Context”直接推导卡顿。Sheet的不同退出路径先保留，后续若统一，应一并覆盖整页／半屏、取消、重开、焦点和presence语义。

三个App当前只共享语义、生产来源交换和验收场景。Swift公共包需要两个稳定的实际消费者才建立；HG没有因此引入跨语言基础类、第二套导航或通用播放器。重构的验收是旧重复路径被删除、状态与副作用只有明确owner、实际入口继续工作。
